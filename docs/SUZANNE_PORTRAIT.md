# Suzanne — Portrait V1

Créé le 12 octobre 2026 à la demande de Hugo, avec l'outil intégré ImageGen (pas de script ni de clé API du projet). Aucune photographie fournie. Personnage fictif de jeune adulte, environ 18–20 ans. Image générée et inspectée visuellement ; fichier original copié sans modification dans le dépôt.

Asset : `apps/web/public/suzanne-portrait-v1.png`. Utilisé dans la carte d'accueil et la présentation de Suzanne ; le cadrage circulaire de l'avatar est appliqué par CSS. Les textes de l'interface et les alternatives d'image indiquent qu'il s'agit d'une IA fictive. La référence visuelle demandée ne constitue pas une collaboration ou un soutien de la personnalité citée.
